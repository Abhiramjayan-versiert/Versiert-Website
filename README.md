# Versiert Media — Official Website

Premium, cinematic, fully static website for **Versiert Media**, a creative media production company in Thiruvananthapuram (Trivandrum), Kerala.

- **Stack:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide icons · Geist typeface (bundled locally)
- **Output:** fully static export (`/out`). No server, no database, no paid services.
- **Hosts:** Vercel (Pro) or any free static host that allows commercial use (Cloudflare Pages recommended). See [DEPLOYMENT.md](./DEPLOYMENT.md).

---

## Run locally

Requires Node.js 20.9+ (tested on Node 22).

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:3000.

Production build (writes the static site to `/out`):

```bash
npm run build
```

Preview the production build:

```bash
npm start
```

Type-check:

```bash
npm run lint
```

## Project structure

```
app/                 Root layout, page, SEO (metadata, sitemap, robots), icons, OG image, 404
components/          One component per section + shared UI (Header, Hero, Services, Work…)
data/                ★ All editable website content lives here

public/videos/       Optional self-hosted hero reel / hover previews

```

### Adding a portfolio project

Add an object to the `projects` array in `data/projects.ts`:

```ts
{
  id: "brand-x-launch",
  title: "Launch Film",
  category: "Commercial Films",         // must be one of `categories`
  client: "Brand X",                    // optional, only with permission
  year: "2026",                         // optional
  thumbnail: "/images/work/brand-x.webp",
  previewVideo: "/videos/brand-x-loop.mp4", // optional muted hover loop (≤ 3 MB)
  videoUrl: "https://youtu.be/XXXXXXXXXXX", // YouTube, Vimeo or .mp4
  description: "One or two sentences about the project.",
  layout: "wide",                       // "wide" (landscape) or "tall" (portrait)
}
```

Delete the sample entries (`isSample: true`) as you add real ones. Category filters and counts update automatically.

## Images and videos to replace

Every image is an **original abstract placeholder** generated by `scripts/generate-placeholders.mjs`. None are stock photos. Replace each one with a real still under the same filename (or update the path in `/data`).

| File | Used for | Recommended size |
| --- | --- | --- |
| `public/images/hero/hero.webp` | Hero background / video poster | 2400×1350 (16:9) |
| `public/images/about/about-1.webp` | About, large portrait | 1200×1500 (4:5) |
| `public/images/about/about-2.webp` | About, small inset | 1200×900 (4:3) |
| `public/images/services/*.webp` (8 files) | Services list (one per service) | 1200×1500 (4:5) |
| `public/images/work/sample-01…08.webp` | Portfolio thumbnails | 1920×1080 (wide) / 1200×1500 (tall) |
| `public/images/contact/contact.webp` | Contact backdrop | 2000×1200 |
| `app/opengraph-image.png` | Link previews (WhatsApp, LinkedIn…) | 1200×630 PNG |

**Optional videos**

- Hero showreel: set `hero.video.mp4` / `hero.video.webm` in `data/content.ts`. Keep it 10–20 s, muted, ≤ 1080p, ideally under 6 MB. Larger reels should go on a CDN or video host. It is not loaded for visitors with reduced-motion or data-saver turned on.
- Portfolio hover loops: `previewVideo` per project (≤ 3 MB).
- Full project films: host them on YouTube or Vimeo and paste the link into `videoUrl`. Don't put large video files in the repository.

**Image tips:** export WebP at quality 70–80 and keep files under ~300 KB. Images aren't resized at runtime (static export), so export them at the sizes above.

## Contact form

The form validates every field. It sends in one of three ways, depending on configuration:

1. **Web3Forms** (free): set `NEXT_PUBLIC_WEB3FORMS_KEY`.
2. **Formspree** or any compatible endpoint (free tier): set `NEXT_PUBLIC_FORM_ENDPOINT`.
3. **Neither set (current default):** a mailto fallback opens the visitor's email app with the enquiry pre-filled. The site tells the visitor to press send; it never shows a fake "sent" message.

A success message appears only after the backend confirms delivery. A failed request shows an error with an email fallback link. A hidden honeypot field filters basic bots.

See `.env.example`. Add the variable in your hosting dashboard, then redeploy.

## Accessibility and performance notes

- Semantic landmarks, one `h1`, a logical heading order, a skip link, visible focus states, labelled form controls with inline errors, and a focus-trapped project dialog (Esc and ← → keys).
- Respects `prefers-reduced-motion`: parallax, marquee, timecode and reveals are disabled.
- The custom cursor only appears on mouse/trackpad devices, and the native cursor is never hidden.
- Lighthouse, served with compression as on a real host: **Mobile 91–92 Performance**, **Desktop 97**, with **100** for Accessibility, Best Practices and SEO.
